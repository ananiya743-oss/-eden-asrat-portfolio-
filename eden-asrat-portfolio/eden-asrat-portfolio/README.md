# Eden Asrat — Portfolio

A polished, editorial-style portfolio website for **Eden Asrat**, a 24-year-old social media & video host based in Addis Ababa, Ethiopia. Open to full-time, freelance and contract roles across Ethiopia.

Built with **Next.js 16 · TypeScript · Tailwind CSS 4 · shadcn/ui · Framer Motion**.

## What's inside

- **Hero** — Open-to-work badge, Eden's portrait, Download CV / Let's connect CTAs
- **About** — Bio, quick facts (Age 24 · 1.67m · Addis Ababa · Open to work)
- **Specialties** — 7 skill cards covering live streaming, video hosting, brand campaigns, event MC, editorial, audience connection, cross-cultural reach
- **Capabilities** — 4 service cards: Live Stream Hosting, Video Hosting, Brand & Campaign Hosting, Event MC & Appearances
- **Why hire Eden** — 4 strength cards + a downloadable CV callout
- **Portfolio gallery** — 5 photos in an editorial grid with a keyboard-navigable lightbox
- **Contact** — Phone/WhatsApp (+251 940 938 770), Instagram (@Eddieas21), Telegram, Addis Ababa location
- **Footer** — Ethiopia-focused, with social links and quick navigation

## Deploy

This site deploys as a **static export** to GitHub Pages — see [`DEPLOY.md`](./DEPLOY.md) for full instructions.

Quick start:

```bash
git init && git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/REPO_NAME.git
git add -A && git commit -m "Initial commit" && git push -u origin main
```

Then enable GitHub Pages → Source: **GitHub Actions** (in repo Settings → Pages).

## Develop locally

```bash
bun install
bun run dev      # dev server on http://localhost:3000
bun run lint     # ESLint
bun run build:gh # static export to ./out (for GitHub Pages)
```
